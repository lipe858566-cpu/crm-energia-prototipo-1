SOLARFLOW CRM PREMIUM - PROTÓTIPO FRONT-END

Como executar:
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra index.html.
4. Use Live Server (recomendado) ou abra diretamente no navegador.

Esta versão possui interface completa e responsiva, animações, dashboard, gráficos CSS,
clientes, usinas, cobranças, relatórios, modal de cadastro, busca e feedback visual.

Ainda é um protótipo front-end. Para produção:
- banco de dados e autenticação
- usuários/permissões
- armazenamento de PDFs
- OCR/leitura da conta de energia
- cálculo real por unidade consumidora
- Pix/boleto via provedor
- histórico e auditoria
- API/backend
